Yukibana is a highly customizable IDE which aims at providing students with
a tailored experience to gradually introduce features as the course progresses.
It also provides teachers with an simple yet powerful tool to configure,
distribute, manage and collect assignments.

## Developing

Developers eager to contribute to this project can find some info
to get started in [CONTRIBUTING.md](CONTRIBUTING.md).
